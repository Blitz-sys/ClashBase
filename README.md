**ClashBase** is a website that allows users to copy and create bases. I eventually want to turn this into something similar to **ClashChamps** where you can get information on anything clash related, but I do need to keep it fast and have an easy learning curve. There will be a different mobile site as this is strictly desktop supported, but as of now there is no mobile website available. This may later have to be ad supported but as of now it has no ads.
